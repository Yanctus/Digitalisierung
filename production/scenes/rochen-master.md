# ROCHEN_MASTER — der Splitterrochen als Webebene

**Ausnahme:** Für dieses eine Bild entfällt „no creatures or fish" aus dem
Stilblock — es ist das einzige Asset, das eine Kreatur zeigen darf.

Auf schwarzem Grund, damit ihn die Seite per `mix-blend-mode: screen`
freistellen kann. Minimax liefert keinen Alphakanal; bei einem leuchtenden
Wesen auf Schwarz ist Screen-Blending sauberer als jede Freistellung.

A long thin trailing tail draws behind it. Elegant, constructed, calm, never cute and never cartoonish. Centred and complete, nothing cropped, with a generous empty margin on all sides.
